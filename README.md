# MyHome Ke

MyHome Ke is a real estate website built with Next.js, React, and Tailwind CSS. It includes a responsive homepage, property highlights, account screens, and legal information pages.

## Development

Install dependencies with `npm install`, then start the development server with `npm run dev`.

Open [http://localhost:3000](http://localhost:3000) to view the site.

Run `npm run lint` to lint the project and `npm run build` to create a production build.

The public-facing brand name is centralized in `components/config/brand.ts`.
